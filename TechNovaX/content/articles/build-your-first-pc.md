Building a PC is like adult LEGO — if you follow the order.

## Choose compatible parts

1. **CPU** and **motherboard** must share a socket (e.g. AM5 or LGA1700).
2. **RAM** type must match the board (DDR4 vs DDR5).
3. **PSU** wattage = GPU + CPU draw + 30% headroom.
4. **Case** must fit the GPU length and cooler height.

## Assembly order

1. **Outside the case:** install CPU, cooler and RAM on the motherboard.
2. Install the M.2 SSD (if the board has a slot).
3. Mount the PSU, then the motherboard on standoffs.
4. Plug in the 24-pin and CPU 8-pin power cables.
5. Install the GPU and connect its PCIe power.
6. Connect front-panel cables (power switch, USB, audio).

## First boot

- Plug the monitor into the **graphics card**, not the motherboard.
- If nothing displays, reseat the RAM — it's the #1 cause.
- Enter BIOS and enable **XMP/EXPO** to run RAM at rated speed.

## Install the OS

Create a USB installer on another PC, boot from it, and install to the SSD.

> Ground yourself by touching the bare metal case before handling parts.
