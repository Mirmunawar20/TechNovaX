আজ আমরা শিখব কীভাবে একটি নতুন রাউটার সম্পূর্ণ সেটআপ করতে হয়।

## যা যা লাগবে

- একটি রাউটার
- একটি ISP সংযোগ (PPPoE আইডি/পাসওয়ার্ড)
- একটি ল্যান কেবল
- একটি কম্পিউটার বা মোবাইল

## ধাপ ১: রাউটার সংযুক্ত করুন

রাউটারের WAN পোর্টে ISP কেবল লাগান এবং LAN পোর্টে কম্পিউটার।

## ধাপ ২: রাউটারে লগইন করুন

ব্রাউজারে যান: `192.168.0.1` অথবা `192.168.1.1`

```text
Username: admin
Password: admin
```

> সেটআপ শেষে অবশ্যই ডিফল্ট পাসওয়ার্ড বদলে ফেলুন।

## ধাপ ৩: ইন্টারনেট (PPPoE) কনফিগার করুন

1. **Internet / WAN Setup** মেনুতে যান।
2. Connection Type হিসেবে **PPPoE** নির্বাচন করুন।
3. ISP থেকে পাওয়া Username ও Password বসান।
4. **Save/Apply** চাপুন — কয়েক সেকেন্ডে Status "Connected" দেখাবে।

## ধাপ ৪: WiFi সুরক্ষিত করুন

- SSID (নাম) দিন, যেমন `MyHome-5G`
- Security: **WPA2/WPA3**
- কমপক্ষে ১২ অক্ষরের শক্ত পাসওয়ার্ড দিন

## সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| Internet নেই কিন্তু WiFi আছে | PPPoE ইউজারনেম/পাসওয়ার্ড আবার চেক করুন |
| 192.168.0.1 খুলছে না | কম্পিউটারে IP "Obtain automatically" করুন |
| ধীর গতি | WiFi চ্যানেল বদলে 1/6/11 এর একটি দিন |
